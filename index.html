04   Methodology

Read the fine print. Please.

We’re tired of vendor benchmarks and we assume you are too. Here’s what our evaluation means, and what it doesn’t.

What is paired scoring, precisely?

For each CVE we have a repo and two SHAs: vuln_sha (the commit the CVE was filed against) and fix_sha (the merge that closed it). We run the scanner on both and call the finding “real” only if it fires on vuln_sha at a location whose scope includes the fixed code, and does not fire on fix_sha. Any other pattern is not credited. Raw alert counts across scanners aren’t comparable; paired scoring is.

Which tools did you compare against?

We’ll publish the exact tool names, versions, and configurations at launch, alongside the reproducible harness. For now the comparison is against the tools most teams actually run today.

Will the corpus be public?

Yes. The evaluation corpus and harness will be open and reproducible. Configurations for every tool under test will be pinned.

When can I try it?

Ward is pre-release and in active development. There’s no public install today. If you want to be notified when there is, leave your email below.
